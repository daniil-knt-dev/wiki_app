# WikiApp

Консольный скрипт на Python для поиска статей через API Wikipedia.

## Требования

* Python 3.8+
* `requests`

## Установка и запуск

1. Клонируйте репозиторий или скачайте файл скрипта.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   Или установите библиотеку вручную:
   ```bash
   pip install requests
   ```
3. Запустите скрипт:
   ```bash
   python main.py
   ```
